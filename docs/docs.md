# Documentation

## Modding

A mod is a collection of files to change the way the game behaves. The root of any mod is a Lua file, but a mod may also have custom levels, textures, audio, and more.

Documentation for modding can be found [in the modding documentation](lua/modding.md).

## Modeling

Modeling can be used for having custom models in your mod or creating custom DynOS packs. It requires some custom tooling to be able to be done properly.

Documentation for modeling can be found [in the modeling documentation](modeling/modeling.md).
